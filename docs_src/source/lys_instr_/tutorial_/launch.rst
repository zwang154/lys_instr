Launch *lys_instr*
------------------

Go to the directory where you want to work, then start *lys*::

    python -m lys

*lys_instr* GUIs are launched from the *lys* platform, which provides tools for multi-dimensional data display and analysis.

This tutorial already covers the necessary *lys* operations. For more details, interested users can refer to the `lys tutorial <https://lys-devel.github.io/lys/tutorials/introduction.html>`_.
